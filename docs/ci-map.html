Environments

The map walks two environments: ci-prod (pre-merge and main) and ci-release. The same Jenkins module (modules/jenkins) runs on four more controllers; only the host config differs: which pipelines, builders, cache, test agents and signing keys it uses. The GitHub Actions row is what runs outside Jenkins.

Supporting services

Hosts ghaf-infra runs that are not on a build route. They keep the CI reachable and observable, or serve the devices Ghaf builds.
